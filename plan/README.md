# plan/

本目录用于存放 AI Agent / 开发者在动手前生成的 **执行计划**（Markdown）。

详细使用规范见 [AGENTS.md](../AGENTS.md) 第 7 节《执行计划目录》。

## 命名

`YYYY-MM-DD-<short-slug>.md`，例如：

```
2026-06-16-webhook-trigger.md
2026-07-02-refactor-deploy-stream.md
```

## 推荐结构

1. **背景与目标**：要解决什么、不解决什么
2. **影响范围**：涉及的子项目、文件、API、DB 表
3. **方案**：关键设计决策 / 备选方案对比
4. **拆解步骤**：可独立验证的小步
5. **验证策略**：手动用例 / 自动测试 / `bun run build` 检查项
6. **风险与回滚**

## 使用约定

- 仅对"新增功能 / 较大重构 / 跨模块改动"必须先写计划；单文件单函数的小修复无需。
- 计划与用户确认后再编码；编码过程中如发现方案需调整，**先回头改计划**。
- 已完成的计划保留在本目录作为决策档案，不要删除。
